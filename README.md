# Index
Index is a simple journal for people whose thoughts move faster than their hands.

It lets users dictate daily entries, edit the transcript, and keep the final writing in their own voice. The journal itself is not written, rewritten, summarized, or interpreted by AI. AI is only used around the edges: transcription, question detection, source finding, and semantic search.

The goal is to preserve fast thoughts, then make it easier to follow them into real sources and personal synthesis.

## Features
* Dictate and edit daily journal entries
* Save and download entries
* Open a collapsible Reading Room sidebar
* Detect questions from saved entries
* Find real sources instead of AI summaries
* Save readings and write thoughts beside them
* Search past entries semantically

* shadcn/ui
